# Перенос BEK264 на Cloudflare за 0 ₽

Бот принимает сообщения из Telegram через webhook. Cloudflare запускает обработчик по мере поступления сообщений. Оценки, участники и VIP-права хранятся в постоянной SQLite-базе Durable Object на тарифе **Workers Free**. Для небольшой группы предусмотрены бесплатные лимиты. По исчерпании лимита запросы могут временно завершаться ошибкой. [Тариф и лимиты](https://developers.cloudflare.com/durable-objects/platform/pricing/).

### 1. Подготовь приложение

1. Войди в [Cloudflare](https://dash.cloudflare.com/), открой **Workers & Pages → Create application** и выбери импорт существующего репозитория GitHub. Дай доступ к `spyCHka/BEK264_rating_bot`. Выбери план **Workers Free** и бесплатный адрес `workers.dev`.
2. Имя приложения — `bek264-rating`, ветка — `main`, корневая папка проекта — `cloudflare`. В качестве команды сборки укажи `python3 ../scripts/check_ratings.py && python3 build.py`, команды публикации — `npx --yes wrangler@4.168.0 deploy`. Эти команды используют и общие Python-модули из корня репозитория. Нажми **Deploy**.
3. В созданном Worker открой **Settings → Variables and Secrets → Add**. Выбери тип **Secret**, имя `BOT_TOKEN` и вставь действующий токен этого Telegram-бота из BotFather. Сохрани через **Deploy**. Секрет нужен работающему приложению. Сборка кода обходится без токена.
4. Открой адрес Worker со страницы **Overview**, добавив `/health`. Ответ `BEK264 webhook` означает, что приложение развёрнуто. До переноса базы оно ожидает журнал. Сохрани адрес без `/health` для следующего шага.

### 2. Забери журнал с Altare

Чтобы перенести все выставленные оценки, нужен последний журнал. Если узел недоступен, дождись восстановления или запроси у поддержки последний согласованный снимок и его дату. Восстановление из более старой копии вернёт состояние на время этого снимка.

Перед окончательным копированием останови старое приложение, чтобы между копированием и переключением никто не успел поставить новую оценку. Скачай папку `/home/container/data/` целиком. В ней находится файл `journal-<ID бота>.sqlite3`. Если рядом есть `-wal` и `-shm`, сохрани их в той же папке под исходными именами. Оставь исходную копию у себя. Это приватные данные группы.

### 3. Перенеси и проверь

На Mac скачай исходники через **GitHub → Code → Download ZIP**, распакуй архив и открой Терминал в папке, где видны `bot.py` и `cloudflare/`. Подставь полный путь к файлу базы и адрес своего Worker. Для этих команд достаточно Python 3.

```bash
python3 cloudflare/transfer.py "/путь/к/journal-123456.sqlite3" "https://bek264-rating.ТВОЙ-ПОДДОМЕН.workers.dev"
```

Скрипт запросит токен в скрытом вводе, проверит принадлежность базы этому боту и загрузит согласованную копию. Он сверяет контрольную сумму, количество строк во всех таблицах и связи между записями. Обрыв соединения допускает повтор той же команды с той же исходной копией. Перенос выводит число карточек и оценок. Подтверждённый импорт блокирует перезапись журнала другой копией.

### 4. Переключи Telegram

После успешной проверки базы и остановки старой копии повтори команду с флагом `--activate`:

```bash
python3 cloudflare/transfer.py "/путь/к/journal-123456.sqlite3" "https://bek264-rating.ТВОЙ-ПОДДОМЕН.workers.dev" --activate
```

Telegram сохранит прежние имя и чат бота. Проверь `/table`, число оценок и свою кнопку управления VIP. Следующие изменения, отправленные в `main`, Cloudflare будет забирать через подключённый GitHub. Последняя серверная база остаётся в том же Durable Object при новых сборках. Адрес для Telegram меняется только по отдельной команде активации.
